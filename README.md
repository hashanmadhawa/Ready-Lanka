# ReadyLanka

Commit 1 creates the Expo React Native foundation for the ReadyLanka emergency-preparedness app.

## Run

```bash
npm install
npx expo start
```

## Five-commit plan

1. Create the Expo project and verify the starter screen.
2. Add local emergency data, guide search and emergency detail advice.
3. Add the emergency-kit checklist and progress display.
4. Add favorites, contacts and AsyncStorage persistence.
5. Polish the interface, add safety notes and complete documentation.
